Help Page

So Jesus said, "Truly I tell you, that this poor widow has thrown in more than everyone else.!"...Luke 21:3

The Ark Bible is an open-source Bible application project, that can be freely distributed by anyone for use in spreading God's holy word. The Ark Bible contains 12 English language versions of the Bible. If you are experiencing any erratic behavior in "The Ark Bible", it can usually be fixed by clicking on the Reset Defaults link at the bottom of the main page, and reloading it twice to clear the serviceworkers.


1. Theme
Theme

The Theme button changes the theme from the light theme to the dark theme, and vice versa.


2. Font
- Font +

The Font buttons increase and decrease the font size. Clicking the plus '+' button increases the font size, and clicking the minus '-' button decreases the font size. Clicking the actual Font button resets the font to the default font size.


3. Red Letter
Red Letter

The Red Letter, Blue Letter, Black Letter button function cycles through black, red, and blue lettering for words spoken by Jesus. This button is currently only available for the partially edited chapters in the Twenty-First Century Version of the Bible. Eventually other chapters and versions will be capable of using this functionality, but not today. The Red Letter - Blue Letter - Black Letter button is currently not visible for the other Bible versions.


4. Paragraph Layout
Paragraph Layout

The Paragraph Layout button cycles between unformatted line layout and paragraph layout for each chapter. The Paragraph Layout - Line Layout buttons functionality is currently only available for the partially edited chapters in the Twenty-Fist Century Version of the Bible. Eventually other chapters and versions will be capable of using this functionality, but not today. The Paragraph Layout - Line Layout button is not visible for this functionality for the other Bible versions.


5. Reset Defaults
Reset Defaults

The Reset Defaults button resets the settings in the app back to the default settings. It also deletes any data stored on your device, and the next time you run the app it will ask you if you want to allow data to be stored locally. If you click cancel, nothing will be stored on your device. If you change your mind later and want to have access to the app offline, just click the Reset Defaults button, and restart you browser. If you have an internet connection you can choose to have the files stored on your device or not.


6. Local Storage

📊--- If you decide not to store files locally, The Ark Bible app will still perform well. If you decide to store The Ark Bible app files locally, all the files for the app will be stored locally in your browser cache as each page, such as this Help page is accessed. All the verse files for each version will be stored locally as you change Bible versions. The first time you use a Bible version listed in the Versions menu or open another page that is part of the app, it will require an internet connection. Once you have accessed a version or another page within the app for the first time, it will also be stored locally. Once stored all the files required by the app will be available without an internet connection. After being saved locally the app will not require an internet connection, unless you try to access a version of the Bible that has not yet been saved locally. All of The Ark Bible operational files requires approximately 90kb of local browser storage space. The verse files for The Ark Bible requires approximately 1.6MB of local storage for each Bible version, and to store all 12 versions would require approximately 19.2MB of local storage space. Each version is only stored once, and you must have an active internet connection the first time you access a version. All of these files can be deleted and the default settings can be reset by either clicking the Reset Defaults link on the main page, or deleting your browser history.


7. The Ark QR Code Link

💥--- The Ark QR Code Link button will display a QR Code that you can scan with your device to open The Ark Bible without having to type it into your browser address bar. Or you can let someone else scan it with their device if you want to share the app with others.


8. The Listen to the Bible

🔊--- The Listen to the Bible button for The Ark Bible opens a page that uses the browsers built-in speech synthesis functionality that audibly reads the Bible. You can play one chapter at a time, or you can set it for continuous play and listen to the entire Bible as it is being read to you while you do other things.


9. The 365 Day Chronological Reading Plan

⚖️--- The 365 Day Chronological Reading Plan is a feature of The Ark Bible that is now available. It is an arrangement of the Bible with the chapters listed in chronological order as they happened historically. This arrangement comes from a chronological list prepared by the Blue Letter Bible, which can be seen here.

Blue Letter Bible Chronological Reading Plan

10. Search The Ark Bible
⚲

--- Search The Ark Bible button opens a very simple spelling and case sensitive search function to search for words or phrases in each Bible version of The Ark Bible. You can search for individual words or exact phrases, and it will return verses for all occurrences of the exact phrase first, then any other occurrence of any words in the phrase will be listed as they occur in the active Bible version.





11. Sort books in The Ark Bible
🩵

--- Click the heart in the Books menu title bar to change the sort direction of the books list from a Biblical sort order to an alphabetically sorted book list.
