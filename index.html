Installed?

Click Install if you agree to allow The Ark Bible app to be installed and store performance files locally, but you do not have to install this app to use it. The Ark Bible app does not collect or store any personal or tracking data. If you click Cancel, no files will be stored locally. If you change your mind, you can reset the app by clicking the Reset Defaults button at the bottom of the page, or by clearing your browser history. More information about the files stored can be found if you click on the Help link at the bottom of the page. If you allow the files to be stored locally it will dramatically reduce data transfer usage for your internet connection.
